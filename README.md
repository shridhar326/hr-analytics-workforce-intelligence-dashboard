## 📊 Project Overview
Built to replace manual spreadsheet reporting with an automated, interactive 
HR dashboard suite. Delivers workforce intelligence to CHROs, CEOs, and HR 
Business Partners for strategic people decisions.

## 🛠️ Tech Stack
- **Visualization:** Power BI
- **Data Transformation:** Power Query (M Language)
- **Calculations:** DAX Measures
- **Data Modeling:** Star Schema
- **Supporting Tool:** Microsoft Excel

## 🗄️ Data Sources
| Source | Data Extracted |
|--------|---------------|
| HRone HRMS | Employee master, attendance, payroll, leave |
| 247HRM | Recruitment, performance, engagement data |

## ✨ Features & Highlights
- Attrition analysis by department, tenure band, and role
- Recruitment pipeline tracking — funnel conversion, time-to-hire, sourcing ROI
- Compensation benchmarking — salary bands, pay equity, incentive distribution
- Performance dashboard — ratings, goal completion, promotion trends
- Automated monthly HR scorecards via Power Query data refresh

## 📈 Business Impact
- Identified flight risk patterns enabling targeted retention strategies
- Reduced manual reporting effort significantly through automation
- Delivered insights to 40+ client organizations at CHRO/CEO level
- Improved workforce budget visibility and headcount cost tracking
